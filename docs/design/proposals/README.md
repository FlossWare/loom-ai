# Design Proposals

These documents are **unimplemented proposals**. They describe potential
future directions for loom-ai but do not reflect the current codebase.

Contracts, file paths, and framework references in these documents may be
speculative, outdated, or in conflict with each other. Do not treat them
as implementation guides.

For accurate documentation of what loom-ai supports today, see:

- [README](../../../README.md) -- install, configuration, quick start, examples
- [Architecture](../../architecture.md) -- layered design, extension model, request lifecycle
- [Contracts](../../contracts.md) -- full protocol inventory with backend mappings
- [Clients](../../clients.md) -- client SDK, CLI, tool adapters
