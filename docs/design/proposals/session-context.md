# Design: Persistent Session Context and Unbounded Memory

> Generated by fleet consensus (Gemini 3.5 Flash, Gemini 2.5 Flash, Qwen 3.6-27b).
> Addresses issue #477.

## Overview

This design document addresses the critical need for persistent session context and effectively unbounded conversational memory within the loom-ai framework. Current agent interactions are often limited by the finite context window of large language models, leading to loss of historical context, prior decisions, and task state across turns or restarts.

The core concept is to establish a durable, hierarchical session knowledge store that operates independently of the model's immediate context window. This store will capture the complete interaction stream, extract structured knowledge, generate summaries, and maintain a rich representation of the session's state. When a model invocation occurs, only the most relevant and critical information will be retrieved and injected into the prompt, making the agent's effective working memory much larger and more resilient.

This system will enable long-running agents to maintain task continuity, resume sessions across process restarts, and automatically manage context compaction without losing important information. It complements existing `AgentLoop` and `ContextAssembler` components by providing the underlying durable memory layer that feeds into context construction and budgeting.

## Protocols/Contracts

A new protocol, `SessionKnowledgeStore`, will define the interface for managing session-specific memory. This protocol will be located in `loom_ai/contracts_provider.py`.

```python
# loom_ai/contracts_provider.py
from __future__ import annotations

from typing import TYPE_CHECKING, Any, Protocol, runtime_checkable
from datetime import datetime

if TYPE_CHECKING:
    from loom_ai.models_provider import (
        SessionEvent,
        SessionContextSnippet,
        SessionFact,
        SessionState,
        SessionMemoryConfig,
        KnowledgeGraduationRequest,
    )

# -- Session Memory (#66) -------------------------------------------------------

@runtime_checkable
class SessionKnowledgeStore(Protocol):
    """Manages durable, unbounded session context and conversational memory.

    This protocol defines the interface for storing, retrieving, and managing
    hierarchical session knowledge, enabling agents to operate beyond the
    model's finite context window. It supports raw event capture, summarization,
    structured fact extraction, and intelligent retrieval.
    """

    async def add_event(self, event: SessionEvent) -> None:
        """Adds a new interaction event to the session's raw history."""
        ...

    async def get_recent_context(self, limit: int = 10) -> list[SessionContextSnippet]:
        """Retrieves the most recent interaction snippets."""
        ...

    async def get_summarized_history(self, session_id: str, max_tokens: int) -> list[SessionContextSnippet]:
        """Retrieves summarized historical context for a session, respecting token limits."""
        ...

    async def get_structured_knowledge(self, query: str | None = None) -> list[SessionFact]:
        """Retrieves structured facts or decisions from the session knowledge."""
        ...

    async def retrieve_relevant_context(
        self,
        query: str,
        current_context: list[SessionContextSnippet],
        config: SessionMemoryConfig,
    ) -> list[SessionContextSnippet]:
        """Retrieves context relevant to the current query and existing context,
        prioritizing based on recency, relevance, and configured strategy."""
        ...

    async def pin_context(self, snippet_id: str, reason: str | None = None) -> None:
        """Marks a specific context snippet as important, preventing its compaction."""
        ...

    async def unpin_context(self, snippet_id: str) -> None:
        """Removes the 'pinned' status from a context snippet."""
        ...

    async def compact_session(self, config: SessionMemoryConfig) -> None:
        """Triggers a session compaction process, potentially summarizing or
        discarding less important information based on configuration."""
        ...

    async def graduate_knowledge(self, request: KnowledgeGraduationRequest) -> None:
        """Moves session-specific knowledge into a broader, persistent knowledge store."""
        ...

    async def save_session_state(self, session_id: str) -> SessionState:
        """Persists the current state of the session memory for later resume."""
        ...

    async def load_session_state(self, session_id: str, state: SessionState) -> None:
        """Loads a previously saved session state, resuming the memory."""
        ...
```

## Data Models

The following data models will be defined in `loom_ai/models_provider.py` to support the `SessionKnowledgeStore` protocol.

```python
# loom_ai/models_provider.py
from __future__ import annotations

from dataclasses import dataclass, field
from datetime import datetime
from enum import Enum
from typing import Any, Dict, List, Optional

class SessionEventType(str, Enum):
    USER_INPUT = "user_input"
    AGENT_OUTPUT = "agent_output"
    TOOL_CALL = "tool_call"
    TOOL_RESULT = "tool_result"
    INTERNAL_THOUGHT = "internal_thought"
    DECISION = "decision"
    FACT = "fact"
    SUMMARY = "summary"

class ContextSnippetType(str, Enum):
    RAW_EVENT = "raw_event"
    SUMMARY = "summary"
    FACT = "fact"
    DECISION = "decision"
    TOOL_RESULT = "tool_result"
    PINNED = "pinned"

@dataclass(frozen=True)
class SessionEvent:
    """Represents a single interaction or internal event within a session."""
    id: str
    session_id: str
    timestamp: datetime
    event_type: SessionEventType
    content: str
    metadata: Dict[str, Any] = field(default_factory=dict)
    provenance_id: Optional[str] = None # Link to original source if extracted/summarized

@dataclass(frozen=True)
class SessionContextSnippet:
    """A piece of context, potentially extracted, summarized, or a raw event."""
    id: str
    session_id: str
    timestamp: datetime
    content: str
    snippet_type: ContextSnippetType
    source_event_ids: List[str] = field(default_factory=list) # IDs of original SessionEvents
    confidence: float = 1.0 # Confidence in accuracy/relevance
    freshness_score: float = 1.0 # How recently it was relevant/updated
    is_pinned: bool = False
    metadata: Dict[str, Any] = field(default_factory=dict)

@dataclass(frozen=True)
class SessionFact:
    """A structured fact or decision extracted from session events."""
    id: str
    session_id: str
    timestamp: datetime
    fact_type: str # e.g., "decision", "constraint", "entity"
    content: Dict[str, Any] # Structured data, e.g., {"action": "create_report", "status": "pending"}
    source_snippet_ids: List[str] = field(default_factory=list)
    confidence: float = 1.0
    is_pinned: bool = False
    metadata: Dict[str, Any] = field(default_factory=dict)

@dataclass(frozen=True)
class SessionMemoryConfig:
    """Configuration for session memory behavior, compaction, and retrieval."""
    max_recent_events: int = 20
    max_summary_tokens: int = 1000
    compaction_interval_minutes: int = 60
    retrieval_strategy: str = "hybrid_recency_keyword" # e.g., "recency", "semantic", "hybrid"
    max_retrieved_tokens: int = 2000
    min_confidence_threshold: float = 0.7

@dataclass(frozen=True)
class SessionState:
    """Represents the complete serializable state of a session's memory."""
    session_id: str
    events: List[SessionEvent]
    snippets: List[SessionContextSnippet]
    facts: List[SessionFact]
    pinned_ids: List[str]
    last_compaction_timestamp: Optional[datetime] = None

@dataclass(frozen=True)
class KnowledgeGraduationRequest:
    """Request to graduate session knowledge to a broader knowledge store."""
    session_id: str
    knowledge_ids: List[str] # IDs of SessionFact or SessionContextSnippet to graduate
    target_store_id: str
    reason: str
```

## In-Memory Implementation Strategy

An `InMemorySessionKnowledgeStore` will be implemented in `loom_ai/backends/in_memory_session_knowledge_store.py`. This implementation will use standard Python data structures to simulate the persistent store:

*   **Internal State**:
    *   `_events: List[SessionEvent]`: Stores all raw interaction events.
    *   `_snippets: List[SessionContextSnippet]`: Stores extracted snippets, summaries, and raw event representations.
    *   `_facts: List[SessionFact]`: Stores structured facts and decisions.
    *   `_pinned_ids: Set[str]`: Tracks IDs of pinned context items.
    *   `_session_id: str`: Identifier for the current session.
    *   `_last_compaction_timestamp: Optional[datetime]`: Timestamp of the last compaction.
*   **`add_event`**: Appends the `SessionEvent` to `_events` and creates a corresponding `SessionContextSnippet` of type `RAW_EVENT` in `_snippets`.
*   **`get_recent_context`**: Returns a time-ordered slice of `_snippets` (primarily `RAW_EVENT` types) up to `limit`.
*   **`get_summarized_history`**: For the in-memory version, this will be a placeholder. It might return a few pre-defined `SUMMARY` snippets or a simple concatenation of older `RAW_EVENT` contents, respecting `max_tokens`.
*   **`get_structured_knowledge`**: Filters `_facts` based on a simple keyword match within `SessionFact.content` or `fact_type`.
*   **`retrieve_relevant_context`**:
    1.  Starts with `current_context`.
    2.  Adds `pinned_ids` from `_snippets` and `_facts`.
    3.  Adds recent context from `get_recent_context`.
    4.  Performs a basic keyword search (case-insensitive substring match) on `_snippets` and `_facts` using the `query`.
    5.  Prioritizes results by `is_pinned`, `freshness_score`, and `confidence`.
    6.  Truncates the combined context to `config.max_retrieved_tokens` (using a simple character count as a proxy for tokens).
*   **`pin_context`/`unpin_context`**: Modifies `_pinned_ids` and updates the `is_pinned` flag on the corresponding `SessionContextSnippet` or `SessionFact` in `_snippets` and `_facts`.
*   **`compact_session`**:
    1.  Identifies `RAW_EVENT` snippets older than a threshold (e.g., `config.compaction_interval_minutes`) that are not pinned.
    2.  Simulates summarization by creating a new `SUMMARY` snippet from a batch of these old `RAW_EVENT`s.
    3.  Removes the original old, unpinned `RAW_EVENT` snippets, or marks them as inactive.
*   **`graduate_knowledge`**: In the in-memory implementation, this will primarily log the request, as actual graduation to a broader store is an external integration point.
*   **`save_session_state`/`load_session_state`**: Serializes/deserializes the internal `_events`, `_snippets`, `_facts`, and `_pinned_ids` lists into/from a `SessionState` object.

## Follow-up Implementation Tasks

1.  **Implement `InMemorySessionKnowledgeStore`**: Create the concrete implementation adhering to the `SessionKnowledgeStore` protocol.
2.  **Basic Extraction/Summarization**: Develop rudimentary text-based summarization and fact extraction logic for `add_event` and `compact_session` (e.g., simple keyword extraction, sentence summarization).
3.  **ContextAssembler Integration**: Integrate the `SessionKnowledgeStore` with the existing `ContextAssembler` (from Phase 6) to provide relevant context for model prompts.
4.  **Token Budgeting**: Implement approximate token counting for `retrieve_relevant_context` and `get_summarized_history` to respect `max_retrieved_tokens`.
5.  **Testing**: Develop comprehensive unit and integration tests for all `SessionKnowledgeStore` methods, covering scenarios like session resume, compaction, pinning, and retrieval.
6.  **AgentMemory Integration**: Design how session knowledge can "graduate" into the broader `AgentMemory` (from Phase 5) for long-term, agent-scoped knowledge.
7.  **Future Enhancements**: Plan for integration with external vector databases for semantic retrieval, graph databases for structured knowledge, and advanced LLM-based summarization/extraction.
