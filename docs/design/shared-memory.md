# Design Document: Shared Concurrent Memory Across Loom Sessions (Issue #478)

## 1. Overview

The goal of this design is to enable multiple concurrent Loom agent sessions working on the same project scope to share durable knowledge, facts, constraints, and coordination states. This prevents sessions from having to duplicate full, multi-turn conversation histories in their individual model contexts, optimizing token usage and improving alignment across distributed tasks.

This architecture distinguishes between speculative session-local reasoning (which remains in local session memory) and authoritative project knowledge (which is published to the shared memory layer). It uses an asynchronous, thread-safe memory store with optimistic concurrency control (OCC) and resource locking to prevent race conditions during concurrent execution.

### Architecture & Conceptual Layers

The system comprises four key functional areas:

1. **Shared Knowledge vs. Private Context**: Sessions maintain their local, private conversation histories. Highly authoritative discoveries, context items, constraints, and decisions are explicitly published to the `SharedMemoryStore`. Speculative or incomplete intermediate thoughts remain local to the session.
2. **Provenance Tracking**: Every piece of shared knowledge is bound to a `ProvenanceInfo` record tracking the originating session, agent, timestamp, action/tool context, source files, and project scope.
3. **Concurrency & Conflict Management**: Writes utilize optimistic concurrency control (OCC) versions. If two sessions write to the same key concurrently, or write conflicting facts, a `ConflictResolver` is invoked to halt, flag, or automatically merge/supersede the data.
4. **Coordination & File/Task Locks**: To avoid race conditions when two sessions are modifying the same source files or running overlapping tasks, a lightweight locking protocol (`SessionCoordinator`) is established.

## 2. Protocols and Contracts

These protocols define the abstract interface of the shared memory engine. They are designed using `@runtime_checkable` and leverage asynchronous workflows for high-concurrency capability and future compatibility with external databases (e.g., Redis, PostgreSQL).

```python
from datetime import datetime
from typing import Any, Dict, List, Optional, Protocol, Tuple, runtime_checkable
from dataclasses import dataclass, field

# Forward references for typing
from models import (
    SharedKnowledge,
    SharedFact,
    SharedDecision,
    SharedDiscovery,
    ConflictRecord,
    LockRecord,
    ProvenanceInfo
)


@runtime_checkable
class SharedMemoryStore(Protocol):
    """
    Handles storage, retrieval, and version tracking of project-level shared facts.
    """

    async def read_fact(self, key: str, project_scope: str) -> Optional[SharedKnowledge]:
        """
        Retrieves the latest active version of a shared knowledge point.
        Returns None if it does not exist or has been superseded/deprecated.
        """
        ...

    async def read_all_facts(
        self, 
        project_scope: str, 
        include_superseded: bool = False
    ) -> List[SharedKnowledge]:
        """
        Lists all knowledge within a project scope. Optionally filters out inactive or superseded entries.
        """
        ...

    async def get_relevant_facts(
        self, 
        project_scope: str, 
        query: str, 
        limit: int = 5
    ) -> List[SharedKnowledge]:
        """
        Retrieves facts relevant to a specific query using semantic or keyword search.
        """
        ...

    async def write_fact(
        self, 
        fact: SharedKnowledge
    ) -> Tuple[SharedKnowledge, Optional[ConflictRecord]]:
        """
        Persists a knowledge point. Evaluates if the key already exists and performs
        optimistic concurrency checks. If a conflict is found, returns
        the current fact and a ConflictRecord instead of silently overwriting.
        """
        ...

    async def supersede_fact(
        self, 
        old_fact_id: str, 
        new_fact: SharedKnowledge
    ) -> SharedKnowledge:
        """
        Explicitly marks an older knowledge point as superseded by a newer one,
        updating their statuses atomically.
        """
        ...


@runtime_checkable
class ConflictResolver(Protocol):
    """
    Detects and mitigates contradictory decisions, facts, or overlapping writes.
    """

    async def detect_conflict(
        self, 
        existing: SharedKnowledge, 
        proposed: SharedKnowledge
    ) -> Optional[ConflictRecord]:
        """
        Evaluates semantic or version conflicts between an existing fact and a proposed fact.
        """
        ...

    async def resolve_conflict(
        self, 
        conflict_id: str, 
        resolution_fact: SharedKnowledge
    ) -> SharedKnowledge:
        """
        Applies a chosen resolution to a registered conflict, archiving 
        or deprecating conflicting facts.
        """
        ...


@runtime_checkable
class KnowledgePublisher(Protocol):
    """
    Automates and structures the flow of discoveries and decisions from individual sessions.
    """

    async def publish_decision(self, decision: SharedDecision) -> None:
        """
        Publishes an explicit, authoritative decision or constraint to the shared memory.
        """
        ...

    async def publish_discovery(self, discovery: SharedDiscovery) -> None:
        """
        Publishes an important factual discovery, containing confidence assessments.
        """
        ...

    async def extract_from_event(
        self, 
        session_id: str, 
        event_data: Dict[str, Any], 
        project_scope: str
    ) -> Optional[SharedKnowledge]:
        """
        Analyzes a session-specific event to auto-extract structured facts 
        if confidence exceeds standard thresholds.
        """
        ...


@runtime_checkable
class SessionCoordinator(Protocol):
    """
    Provides lock management, resource allocation, and synchronization tools 
    for concurrent agent sessions.
    """

    async def acquire_lock(
        self, 
        resource_key: str, 
        session_id: str, 
        duration_seconds: float, 
        purpose: str
    ) -> Optional[LockRecord]:
        """
        Attempts to acquire a non-blocking lock on a specific resource 
        (e.g., file path, sub-task key) for a set duration.
        Returns a LockRecord if successful, or None if already locked.
        """
        ...

    async def release_lock(self, resource_key: str, session_id: str) -> bool:
        """
        Releases a lock held by a session. Returns True if released successfully.
        """
        ...

    async def renew_lock(
        self, 
        resource_key: str, 
        session_id: str, 
        additional_duration: float
    ) -> Optional[LockRecord]:
        """
        Renews an existing lock before expiration (heartbeat). Returns updated LockRecord.
        """
        ...

    async def get_lock_status(self, resource_key: str) -> Optional[LockRecord]:
        """
        Queries status of a resource lock to check if active.
        """
        ...
```

## 3. Data Models

All models are designed using `@dataclass(frozen=True)` to ensure strict thread safety, immutability, and protection from accidental side effects.

```python
from dataclasses import dataclass, field
from datetime import datetime
from enum import Enum
from typing import Any, Dict, List, Optional


class FactStatus(str, Enum):
    ACTIVE = "active"
    SUPERSEDED = "superseded"
    DEPRECATED = "deprecated"
    CONFLICT = "conflict"


class ConflictResolutionType(str, Enum):
    UNRESOLVED = "unresolved"
    OVERWRITE = "overwrite"
    MERGE = "merge"
    DISCARD_PROPOSED = "discard_proposed"


@dataclass(frozen=True)
class ProvenanceInfo:
    """
    Tracks origin and context of structural knowledge points.
    """
    session_id: str
    timestamp: datetime = field(default_factory=datetime.utcnow)
    tool_action: Optional[str] = None
    source_artifact: Optional[str] = None  # e.g., "src/main.py"
    project_scope: str = "default"
    agent_id: Optional[str] = None


@dataclass(frozen=True)
class SharedKnowledge:
    """
    Base structural model for all shared memory entries.
    """
    id: str
    key: str
    value: Any
    provenance: ProvenanceInfo
    version: int = 1
    status: FactStatus = FactStatus.ACTIVE
    supersedes_id: Optional[str] = None
    metadata: Dict[str, Any] = field(default_factory=dict)


@dataclass(frozen=True)
class SharedFact(SharedKnowledge):
    """
    A discrete chunk of validated knowledge, managed under version control.
    """
    confidence_score: float = 1.0
    category: str = "general"  # e.g., "environment", "syntax", "requirement"


@dataclass(frozen=True)
class SharedDecision(SharedKnowledge):
    """
    An architectural commitment, constraint, or instruction explicitly 
    agreed upon within a session.
    """
    rationale: str = ""
    alternatives_considered: List[str] = field(default_factory=list)


@dataclass(frozen=True)
class SharedDiscovery(SharedKnowledge):
    """
    An observed pattern, bug discovery, or runtime behavior that may impact execution.
    """
    severity: str = "info"  # "info", "warning", "critical"


@dataclass(frozen=True)
class ConflictRecord:
    """
    Maintains record of a write-write collision or semantic contradiction 
    requiring resolution.
    """
    id: str
    key: str
    existing_fact_id: str
    proposed_fact_id: str
    conflict_type: str  # e.g., "VERSION_MISMATCH" or "SEMANTIC_CONTRADICTION"
    timestamp: datetime = field(default_factory=datetime.utcnow)
    resolution: ConflictResolutionType = ConflictResolutionType.UNRESOLVED
    resolved_fact_id: Optional[str] = None


@dataclass(frozen=True)
class LockRecord:
    """
    Details of a critical lock held on a file or process to align concurrent execution.
    """
    lock_id: str
    resource_key: str
    held_by_session: str
    acquired_at: datetime
    expires_at: datetime
    purpose: str
```

## 4. InMemory Backend Implementation Strategy

To enable seamless testing and lightweight concurrency handling without forcing immediate infrastructure dependencies (like Redis, PostgreSQL, or SQLite), a robust, asynchronous in-memory backend is specified.

### Concurrency and Thread-Safety Architecture

1. **Global Lock and Key-Level Locks**: The store uses `asyncio.Lock` to guarantee atomic operations across concurrent coroutines.
2. **Deep Copy on Read/Write**: Python dictionary operations pass by reference. To guarantee that frozen dataclasses and their nested objects remain pure, a deep copy strategy is applied whenever facts are read from or stored to the memory maps.
3. **Optimistic Concurrency Control (OCC)**: Writes track sequence numbers (`version: int`). If Session A reads version 1 of `config.url`, and writes back version 2, while Session B successfully committed version 2 in between, Session A’s write is flagged with a `ConflictRecord` (`VERSION_MISMATCH`) and blocked from executing until resolved.
4. **Retrieval & Relevance Search**: Since this is an in-memory implementation, semantic matching is mocked using a fast keyword/metadata matching filter. In production, this can easily be swapped with a local vector library (e.g., `FAISS` or `SentenceTransformers`).

### Storage Internals Layout

```python
import asyncio
from copy import deepcopy
from uuid import uuid4


class InMemorySharedMemoryEngine:
    """
    A fully thread-and-coroutine-safe store implementing SharedMemoryStore, 
    ConflictResolver, and SessionCoordinator entirely in-memory.
    """
    def __init__(self):
        self._lock = asyncio.Lock()
        
        # Primary Storage: map project_scope -> (map key -> SharedKnowledge)
        self._facts: Dict[str, Dict[str, SharedKnowledge]] = {}
        
        # Flat history: map fact_id -> SharedKnowledge
        self._fact_history: Dict[str, SharedKnowledge] = {}
        
        # Conflict Records: map conflict_id -> ConflictRecord
        self._conflicts: Dict[str, ConflictRecord] = {}
        
        # Active Locks: map resource_key -> LockRecord
        self._locks: Dict[str, LockRecord] = {}

    # --- SharedMemoryStore Implementation ---

    async def read_fact(self, key: str, project_scope: str) -> Optional[SharedKnowledge]:
        async with self._lock:
            scope_map = self._facts.get(project_scope, {})
            fact = scope_map.get(key)
            if fact and fact.status == FactStatus.ACTIVE:
                return deepcopy(fact)
            return None

    async def read_all_facts(
        self, 
        project_scope: str, 
        include_superseded: bool = False
    ) -> List[SharedKnowledge]:
        async with self._lock:
            scope_map = self._facts.get(project_scope, {})
            results = []
            for fact in scope_map.values():
                if include_superseded or fact.status == FactStatus.ACTIVE:
                    results.append(deepcopy(fact))
            return results

    async def get_relevant_facts(
        self, 
        project_scope: str, 
        query: str, 
        limit: int = 5
    ) -> List[SharedKnowledge]:
        """
        Performs basic substring and metadata filter matching over keys, values, and 
        descriptions to retrieve relevant facts in the in-memory engine.
        """
        async with self._lock:
            scope_map = self._facts.get(project_scope, {})
            active_facts = [f for f in scope_map.values() if f.status == FactStatus.ACTIVE]
            
            query_lower = query.lower()
            matched = []
            
            for fact in active_facts:
                # Textual check of key and value content
                key_match = query_lower in fact.key.lower()
                val_match = False
                
                if isinstance(fact.value, str):
                    val_match = query_lower in fact.value.lower()
                
                # Check subclass properties (e.g., SharedDecision rationale)
                extra_match = False
                if isinstance(fact, SharedDecision):
                    extra_match = query_lower in fact.rationale.lower()
                elif isinstance(fact, SharedDiscovery):
                    extra_match = query_lower in fact.severity.lower()

                if key_match or val_match or extra_match:
                    matched.append(deepcopy(fact))
                
                if len(matched) >= limit:
                    break
                    
            return matched

    async def write_fact(
        self, 
        fact: SharedKnowledge
    ) -> Tuple[SharedKnowledge, Optional[ConflictRecord]]:
        async with self._lock:
            scope = fact.provenance.project_scope
            if scope not in self._facts:
                self._facts[scope] = {}

            existing = self._facts[scope].get(fact.key)

            if existing:
                # 1. Version Conflict / OCC Check
                if existing.version >= fact.version:
                    conflict_id = f"conf_{uuid4().hex[:8]}"
                    conflict = ConflictRecord(
                        id=conflict_id,
                        key=fact.key,
                        existing_fact_id=existing.id,
                        proposed_fact_id=fact.id,
                        conflict_type="VERSION_MISMATCH",
                        timestamp=datetime.utcnow()
                    )
                    self._conflicts[conflict_id] = conflict
                    return deepcopy(existing), deepcopy(conflict)

                # 2. Semantic Conflict Pre-check
                if existing.value != fact.value and fact.supersedes_id != existing.id:
                    conflict_id = f"conf_{uuid4().hex[:8]}"
                    conflict = ConflictRecord(
                        id=conflict_id,
                        key=fact.key,
                        existing_fact_id=existing.id,
                        proposed_fact_id=fact.id,
                        conflict_type="SEMANTIC_CONTRADICTION",
                        timestamp=datetime.utcnow()
                    )
                    self._conflicts[conflict_id] = conflict
                    
                    # Mark existing object status as CONFLICT in the primary map
                    conflicting_fact = SharedKnowledge(
                        id=existing.id,
                        key=existing.key,
                        value=existing.value,
                        provenance=existing.provenance,
                        version=existing.version,
                        status=FactStatus.CONFLICT,
                        supersedes_id=existing.supersedes_id,
                        metadata=existing.metadata
                    )
                    self._facts[scope][fact.key] = conflicting_fact
                    return deepcopy(conflicting_fact), deepcopy(conflict)

            # Valid write or explicit supersede flow
            copied_fact = deepcopy(fact)
            self._facts[scope][fact.key] = copied_fact
            self._fact_history[fact.id] = copied_fact
            
            # Update old record's state on supersession
            if fact.supersedes_id and fact.supersedes_id in self._fact_history:
                old_fact = self._fact_history[fact.supersedes_id]
                
                # Replace with status-updated replica
                updated_old_fact = SharedKnowledge(
                    id=old_fact.id,
                    key=old_fact.key,
                    value=old_fact.value,
                    provenance=old_fact.provenance,
                    version=old_fact.version,
                    status=FactStatus.SUPERSEDED,
                    supersedes_id=old_fact.supersedes_id,
                    metadata=old_fact.metadata
                )
                self._fact_history[fact.supersedes_id] = updated_old_fact
                
                if (
                    self._facts[scope].get(old_fact.key) 
                    and self._facts[scope][old_fact.key].id == old_fact.id
                ):
                    self._facts[scope].pop(old_fact.key, None)

            return copied_fact, None

    async def supersede_fact(
        self, 
        old_fact_id: str, 
        new_fact: SharedKnowledge
    ) -> SharedKnowledge:
        # Re-initialize the new knowledge point explicitly referencing the target ID
        updated_new_fact = SharedKnowledge(
            id=new_fact.id,
            key=new_fact.key,
            value=new_fact.value,
            provenance=new_fact.provenance,
            version=new_fact.version,
            status=new_fact.status,
            supersedes_id=old_fact_id,
            metadata=new_fact.metadata
        )
        saved_fact, conflict = await self.write_fact(updated_new_fact)
        if conflict:
            raise ValueError(f"Supersession failed due to write conflict: {conflict.conflict_type}")
        return saved_fact

    # --- ConflictResolver Implementation ---

    async def detect_conflict(
        self, 
        existing: SharedKnowledge, 
        proposed: SharedKnowledge
    ) -> Optional[ConflictRecord]:
        if existing.key != proposed.key:
            return None
        
        if existing.value != proposed.value and proposed.supersedes_id != existing.id:
            return ConflictRecord(
                id=f"conf_{uuid4().hex[:8]}",
                key=existing.key,
                existing_fact_id=existing.id,
                proposed_fact_id=proposed.id,
                conflict_type="SEMANTIC_CONTRADICTION"
            )
        return None

    async def resolve_conflict(
        self, 
        conflict_id: str, 
        resolution_fact: SharedKnowledge
    ) -> SharedKnowledge:
        async with self._lock:
            conflict = self._conflicts.get(conflict_id)
            if not conflict:
                raise KeyError(f"Conflict with ID {conflict_id} not found.")

            scope = resolution_fact.provenance.project_scope
            
            # Resolve conflict record status
            resolved_conflict = ConflictRecord(
                id=conflict.id,
                key=conflict.key,
                existing_fact_id=conflict.existing_fact_id,
                proposed_fact_id=conflict.proposed_fact_id,
                conflict_type=conflict.conflict_type,
                timestamp=conflict.timestamp,
                resolution=ConflictResolutionType.MERGE,
                resolved_fact_id=resolution_fact.id
            )
            self._conflicts[conflict_id] = resolved_conflict

            # Mark conflicting facts as historical / superseded
            for fid in (conflict.existing_fact_id, conflict.proposed_fact_id):
                if fid in self._fact_history:
                    old = self._fact_history[fid]
                    self._fact_history[fid] = SharedKnowledge(
                        id=old.id,
                        key=old.key,
                        value=old.value,
                        provenance=old.provenance,
                        version=old.version,
                        status=FactStatus.SUPERSEDED,
                        supersedes_id=old.supersedes_id,
                        metadata=old.metadata
                    )

            # Persist resolved fact directly
            self._facts[scope][resolution_fact.key] = resolution_fact
            self._fact_history[resolution_fact.id] = resolution_fact
            return deepcopy(resolution_fact)

    # --- SessionCoordinator Lock Implementation ---

    async def acquire_lock(
        self, 
        resource_key: str, 
        session_id: str, 
        duration_seconds: float, 
        purpose: str
    ) -> Optional[LockRecord]:
        async with self._lock:
            now = datetime.utcnow()
            active_lock = self._locks.get(resource_key)

            if active_lock:
                if active_lock.expires_at > now:
                    return None  # Lock is actively held
                self._locks.pop(resource_key, None)  # Lock expired; clean up

            # Grant lock
            expires_at = datetime.fromtimestamp(now.timestamp() + duration_seconds)
            lock_rec = LockRecord(
                lock_id=f"lock_{uuid4().hex[:8]}",
                resource_key=resource_key,
                held_by_session=session_id,
                acquired_at=now,
                expires_at=expires_at,
                purpose=purpose
            )
            self._locks[resource_key] = lock_rec
            return deepcopy(lock_rec)

    async def release_lock(self, resource_key: str, session_id: str) -> bool:
        async with self._lock:
            active_lock = self._locks.get(resource_key)
            if not active_lock:
                return False
            if active_lock.held_by_session != session_id:
                return False
            
            self._locks.pop(resource_key, None)
            return True

    async def renew_lock(
        self, 
        resource_key: str, 
        session_id: str, 
        additional_duration: float
    ) -> Optional[LockRecord]:
        async with self._lock:
            active_lock = self._locks.get(resource_key)
            if not active_lock or active_lock.held_by_session != session_id:
                return None
            
            now = datetime.utcnow()
            new_expiry = datetime.fromtimestamp(
                max(active_lock.expires_at.timestamp(), now.timestamp()) + additional_duration
            )
            updated_lock = LockRecord(
                lock_id=active_lock.lock_id,
                resource_key=active_lock.resource_key,
                held_by_session=active_lock.held_by_session,
                acquired_at=active_lock.acquired_at,
                expires_at=new_expiry,
                purpose=active_lock.purpose
            )
            self._locks[resource_key] = updated_lock
            return deepcopy(updated_lock)

    async def get_lock_status(self, resource_key: str) -> Optional[LockRecord]:
        async with self._lock:
            now = datetime.utcnow()
            lock = self._locks.get(resource_key)
            if lock and lock.expires_at > now:
                return deepcopy(lock)
            return None
```

## 5. Implementation Roadmap

Integration into the main Loom codebase will be conducted in four progressive phases:

### Phase 1: Core Data Models & Infrastructure Setup
- Create `loom_ai/shared_memory/models.py` incorporating the base class and subclassed knowledge records defined in Section 3.
- Create `loom_ai/shared_memory/protocols.py` containing the `@runtime_checkable` asynchronous protocols from Section 2.
- Write standard validation tests ensuring full dataclass immutability, copy safety, and dictionary serialization pathways.

### Phase 2: In-Memory Engine Development
- Deploy the complete thread-and-coroutine safe implementation in `loom_ai/shared_memory/backends/in_memory.py`.
- Implement rigorous concurrency stress tests verifying:
  - Correct optimistic concurrency control (OCC) version rejections.
  - Verification of deep copies (validating that modifying a retrieved record object outside the engine does not compromise the inner state).
  - Accurate expiration of locks and successful renewal processing under simulated heavy load.

### Phase 3: Agent Integration Layer & Knowledge Publisher
- Create `loom_ai/shared_memory/publisher.py` with concrete extraction rules.
- Integrate automated heuristics or LLM evaluation calls within the publisher to review session actions:
  - Identify high-confidence configuration modifications, API constraints, and architectural decisions, automatically publishing them to the store.
  - Prevent developer conversational chatter from spilling into shared scopes.
- Standardize tool sets within sessions to query `get_relevant_facts` and incorporate those outputs directly into local system prompts.

### Phase 4: Lock Management & Agent Coordination Tools
- Modify file-writing and build-execution tools in Loom to check with the `SessionCoordinator` before executing local modifications.
- Incorporate automatic lock renewal loops ("heartbeats") during long-running background tasks.
- Build exponential back-off and polling models for agents waiting on dynamic lock releases, with user-facing warnings on deadlocked cycles.
